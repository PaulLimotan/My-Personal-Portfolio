CAPSTONE PROJECT PROJECT CODE: #LP-2026

LORAPASS

An Adaptive Traffic Signal Management System Using LoRa RA-02 and ESP32 for Ambulance & Fire Truck Priority.

EMERGENCY PREEMPTION

When an emergency vehicle approaches, LoRa signals automatically request green light passage to reduce delay.

✔ Long-range radio RF technology (LoRa RA-02)
✔ ESP32 dynamic signal processing
✔ Designed specifically for high-density streets like Colon St.
KEY HIGHLIGHTS STATUS: PROTOTYPE

WHY LORAPASS MATTERS

⏱️ Seconds Save Lives Traffic congestion significantly delays emergency responses. LoRaPass clears a green wave for emergency responders safely.
📡 Infrastructure Independent Does not rely on cellular internet; operates via direct long-range radio signals for high reliability during crises.
Target: Colon Street Cebu
SECTION 04

HOW IT WORKS

Step-by-step breakdown of the LoRaPass system architecture.

STEP 01
🚑

VEHICLE TRANSMISSION

The emergency vehicle's onboard ESP32 + LoRa module broadcasts an encrypted priority request signal when dispatched.

STEP 02
📡

LORA RECEIVER GATEWAY

The intersection controller receives the RF signal, calculates distance & direction, and overrides standard light timing.

STEP 03
🚦

GREEN LIGHT WAVE

Traffic lights switch to green safely for emergency vehicles and reset automatically once the vehicle passes through.

CAPSTONE DEEP DIVE

LoRaPass System Architecture

Project Title: LoRaPass: An IoT-Based Adaptive Traffic Signal Management System Using LoRa RA-02 and ESP32 for Ambulance and Fire Truck Priority on Colon Street.

Hardware Components:

  • ESP32 Microcontroller: Manages logic, signal state switching, and communication processing.
  • LoRa RA-02 Module (433MHz): Transmits long-range radio requests through dense urban structures.
  • Traffic Light Module Prototype: Displays synchronized red, yellow, and green signal state overrides.

Implementation Focus:

Tested for the specific urban layout of Colon Street in Cebu City, prioritizing emergency vehicle arrival times while minimizing disruption to side-street traffic flow.
